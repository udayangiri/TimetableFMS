🏫Sections & Time Slots

Create a section, pick its class days, then tick the standard time slots it uses. Breaks are shown but not selectable.

📥Excel Bulk Import / Export — Sections

Required columns (Row 1 = headers, data from Row 2):
section_name  |  slot_start  |  slot_end  |  class_days
ⓘ class_days: comma-separated — e.g. Mon,Wed,Fri  |  Times: HH:MM format — e.g. 07:30
Multiple rows with the same section_name = multiple time slots for that section.
⚠Import appends new rows. Exact duplicate slots are skipped.
